# CH340 USB 드라이버

드라이버는 [WCH 공식 다운로드 페이지](https://www.wch-ic.com/downloads/CH341SER_EXE.html)에서 받으세요.
이 저장소와 전체 설치 묶음에는 드라이버 설치 파일을 포함하지 않습니다.

## 설치 및 포트 확인

1. 제조사 페이지에서 Windows 및 장비의 CH340/CH340K 지원 여부를 확인하고 드라이버를 다운로드합니다.
2. 설치 프로그램을 실행합니다.
3. 장비 USB를 다시 연결하고 Windows 장치 관리자의 <strong>포트(COM 및 LPT)</strong>에서 COM 번호를 확인합니다.
4. 펌웨어 업데이터에서 포트 목록을 새로고침합니다.

| 펌웨어 업데이터 | 표시 대상 | USB VID | USB PID |
| --- | --- | --- | --- |
| 0.3.3 | CH340K | 1A86 | 7522 |

드라이버가 설치되어도 위 대상이 아닌 FTDI·Bluetooth·다른 CH340 변형은 **펌웨어 업데이터**의 목록에 표시되지 않습니다.
포트 인식 문제는 [문제 해결](../../docs/TROUBLESHOOTING.md)을 참고하세요.

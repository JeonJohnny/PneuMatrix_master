# Windows 설치 방법

## 준비할 파일

- [PneuMatrix Control 2.0.0 설치 EXE](https://github.com/JeonJohnny/PneuMatrix_master/releases/download/control-v2.0.0/PneuMatrix-Setup-2.0.0.exe)
- 펌웨어 변경이 필요할 경우 업데이터 설치 EXE 및 장비 HW에 맞는 `.tkfw`
- Windows에서 USB 포트를 인식하지 못하면 제조사 CH340 드라이버

[메인 다운로드 표](../README.md)에서 받으세요. 각 Setup은 설치에 필요한 프로그램 구성요소를 포함합니다. 펌웨어 `.tkfw`는 업데이터 Setup에 포함되지 않습니다.

## 설치 순서

1. 장비 USB를 연결합니다. 포트가 보이지 않으면 [드라이버 안내](../drivers/ch340/README.md)를 따릅니다.
2. PneuMatrix Control Setup을 실행하고 설치합니다.
3. 프로그램을 실행하고 포트·장비 주소를 확인한 뒤 연결합니다.
4. 장비의 모델, HW, 펌웨어 버전을 확인합니다. 펌웨어 업데이트는 필요한 경우에 진행합니다.

## 펌웨어 업데이트

1. 장비 운전을 중지하고 RS485를 분리합니다.
2. PneuMatrix Control과 시리얼 모니터를 종료합니다.
3. 업데이터 Setup을 설치하고 실행합니다.
4. CH340K의 COM 포트를 선택하고 장비를 확인합니다.
5. **펌웨어 파일 선택**에서 사용자 업데이트용 펌웨어 패키지(.tkfw)를 선택합니다.
6. 기본 속도 115200과 운전 중지 확인 후 업데이트를 시작합니다.
7. 새 버전 및 설정 확인이 끝나 완료로 표시될 때까지 기다립니다.

장비 정보 확인에 실패하면 업데이트를 중단하고 본사에 문의하세요.

## 재설치·제거

업데이터 Setup 0.3.3을 다시 실행하면 설치 관리 페이지에서 재설치 / 제거 / 클린 삭제를 선택할 수 있습니다. 클린 삭제는 장비 설정 백업과 작업 기록도 지우며 되돌릴 수 없습니다. 단순 업데이트는 재설치를 선택하세요.

현재 배포는 사전 배포입니다. 장비에서의 첫 사용은 출력 정지 상태에서 연결·식별부터 확인하세요.

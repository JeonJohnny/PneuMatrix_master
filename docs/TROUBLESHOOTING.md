# 문제 해결

## 포트가 보이지 않음

장치 관리자, USB 케이블, CH340 드라이버를 확인합니다. 업데이터는 CH340K만 표시합니다. 다른 USB-UART 장치는 현재 목록에서 제외됩니다.

## 포트를 열 수 없음

제어 프로그램, 다른 업데이터, VS Code 시리얼 모니터를 종료합니다. USB로 장비 한 대만 직접 연결합니다.

## Corrupt data / 설정 백업 읽기 오류

460800에서 백업 데이터를 읽는 중 4096바이트 대신 4046바이트가 수신된 사례가 있습니다. 속도·드라이버·케이블 중 근본 원인은 확정되지 않았습니다.

현재 앱은 115200을 기본값으로 사용합니다. 고속에서 특정 수신 오류가 발생하면 저속으로 백업 읽기를 한 번 재시도합니다. 기본 속도에서도 반복되면 케이블·허브·드라이버 상태를 확인하세요.

백업 전 실패한 `prepared: false` 세션은 복구 재시도 대상이 아닙니다. 파일을 다시 선택해 새 작업으로 시작합니다. 기록 중 실패한 세션은 업데이터의 실패한 업데이트 재시도 기능으로 확인하세요.

## 업데이트 파일 거부

HW 불일치, 손상된 패키지, 장비 정보 확인 실패, 다운그레이드 여부를 확인합니다. `.tkfw`를 압축 해제하거나 수정하지 마세요.

## 설치 중 파일 교체 실패

실행 중인 업데이터를 종료한 뒤 Setup을 다시 실행합니다. 펌웨어 기록 중에는 종료·제거하지 마세요.

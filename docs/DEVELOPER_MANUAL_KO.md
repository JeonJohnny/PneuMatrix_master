## 1. 빠른 참조

명령 앞에는 반드시 주소 한 글자를 붙이고 끝에는 LF(`\n`)를 보냅니다. 아래 `1`은 예시 장비 주소입니다.

| 목적 | 요청 예 | 정상 응답 예 |
| --- | --- | --- |
| 장비 정보 | `1?I` | `1?I,TKPM-D11,v002,v2.8.1,PM26J001,100,100,0,0` |
| 밸브 3 켜기 | `1o3` | `1O3,ON` |
| 밸브 3 끄기 | `1x3` | `1X3,OFF` |
| 모든 밸브 끄기 | `1b00` | `1B00,OK` |
| 밸브 상태 | `1?V` | `1?V,0,0,0,0,0,0,0,0` |
| 밸브 비트마스크 | `1?V/` | `1?V/,00` |
| 1번 설정압 20.5 kPa | `1p1,20.5` | `1P1,20.5,OK` |
| 1번 설정압 조회 | `1?P1` | **`1?P,20.5`** |
| 1번 측정압 조회 | `1?A1` | `1?A1,18.3` |
| 전체 측정압 조회 | `1?A` | `1?A,18.3,0.0,DISABLED,DISABLED` |

예시의 설정압·측정압은 설명용입니다. 실제 ACK 값은 압력 범위·보정·DAC 양자화에 따라 달라질 수 있습니다. **설정압 `?P`와 측정압 `?A`는 서로 다른 값**입니다.

## 2. 연결과 프레임

### 2.1 통신 설정

| 항목 | 값 |
| --- | --- |
| 인터페이스 | USB Serial |
| 속도(Baudrate) | 115200 bps |
| 데이터 / 패리티 / 정지 비트 | 8 / 없음 / 1 (8N1) |
| 흐름 제어(Flow Speed) | 없음 |
| 명령 인코딩 | ASCII |
| 요청 끝 | LF (`\n`), CRLF도 허용 |
| 응답 끝 | CRLF (`\r\n`) |

- 이 속도는 정상 운전 중 제어 통신 기준입니다. 펌웨어 업데이터의 다운로드 모드 속도와 구분하세요.
- RS485는 USB로 연결된 장비에 전달 된 명령을 내부적으로 명령 수신되는 장비 주소의 기기에 다시 전달합니다.

```text
[주소 1글자][명령 본문]\n

예: 1p1,20.5\n
```

- 수신된 CR(`\r`)은 무시하며 LF에서 명령을 처리합니다. 빈 줄은 무시합니다.
- 줄 양끝의 공백은 제거되지만, 명령·숫자 사이에 임의 공백을 넣지 마세요.
- 현재 통신 버퍼는 LF·CR을 제외하고 최대 127글자를 저장합니다. 초과 부분을 잘라내므로 호스트는 긴 프레임을 보내지 않아야 합니다. 길이 초과에 대한 별도 오류 응답은 없습니다.
- 요청 ID나 프레임 체크섬 필드는 없습니다. 호스트는 한 번에 하나의 요청을 보내고 응답 또는 타임아웃을 처리한 뒤 다음 요청을 보내는 방식을 권장합니다.

### 2.2 주소와 USB 브리지

| 주소 | USB에서의 의미 | RS485에서의 의미 |
| --- | --- | --- |
| `0` | USB에 직접 연결된 장비 | 주소 0 요청은 무시 |
| `1–9`, `A–F` | 로컬 주소이면 실행, 다른 주소이면 RS485로 전달 | 자기 주소의 요청만 실행 |

유효한 장비 주소는 `1, 2, 3, 4, 5, 6, 7, 8, 9, A, B, C, D, E, F`입니다. `A–F`는 10부터 15까지의 16진수 표기입니다.

주소의 16진수 영문자는 대소문자를 모두 받으며 응답은 대문자로 표시합니다. `0`은 전체 장비에 명령하는 브로드캐스트 주소가 아닙니다. 응답 주소는 요청 주소를 따릅니다. 예를 들어 `0?I`의 응답은 `0?I,...`입니다.

RS485 버스에서는 장비별로 서로 다른 주소를 사용합니다. 주소 변경은 USB 직결의 `0n<주소>`로만 가능합니다(9절).

### 2.3 대소문자

| 명령 | 규칙 |
| --- | --- |
| `o`, `x`, `b`, `p` | **소문자로 전송** |
| `?I`, `?V`, `?A`, `?P` | 대소문자 모두 허용 |
| 설정 ACK | `O`, `X`, `B`, `P`처럼 대문자 |
| 주소 변경 `n` | `n`, `N` 모두 허용 |

예를 들어 `1P1,20`은 설정 명령이 아닙니다. USB 로컬 요청에서는 `ERR-102`가 발생하며, RS485에서는 대문자+쉼표 형식이 응답으로 분류되어 중계될 수 있습니다. 설정 명령의 대소문자를 바꾸지 마세요.

## 3. 장비 식별 및 채널 구성

### 3.1 장비 정보 — `[ADDR]?I`

```text
요청: 1?I
응답: 1?I,TKPM-D11,v002,v2.8.1,PMABCD001,100,100,0,0
```

| 응답 필드 (`1?I` 다음부터) | 의미 |
| --- | --- |
| 1 | 모델명 |
| 2 | H/W 버전 |
| 3 | 실행 중인 F/W 버전 |
| 4 | 장비 S/N |
| 5–8 | 레귤레이터 1–4의 최대압, 정수 kPa |

- 모델·H/W·S/N·채널 최대압은 장비에 저장된 값을 사용합니다. F/W 버전은 실행 이미지의 버전입니다. 
- 위 모델과 S/N은 설명 용 예시이며 프로그램에 적용 시 오류가 발생합니다.
- 최대압 `0`은 **미장착/비활성 구성**입니다.
- 연결 직후 `?I`를 요청해 장비를 확인하세요. 유효한 프로필이 없으면 식별 정보에 `UNPROVISIONED`가 나타날 수 있습니다. 이 상태에서는 일반 운전을 시작하지 말고 본사에 지원을 요청합니다.

### 3.2 활성 채널

```text
실제 활성 채널 = 사용할 수 있는 압력 조절 옵션 수. (구매 시 또는 추가 업그레이드 된 장비에 따라 상이함)
```

- 비활성 채널의 `p` 설정: `ERR-301`.
- 비활성 채널의 개별 `?A`, `?A/`, `?P`, `?P/` 조회: `DISABLED`.
- 전체 `?A`: 네 필드 중 비활성 채널 위치에 `DISABLED`.
- `?I`는 저장된 최대압을 표시합니다.

## 4. 밸브 제어

8개 밸브를 제어합니다. 밸브 상태 조회는 출력 지령 상태이며 실제 기계적 개폐를 측정하는 센서 응답이 아닙니다.

### 4.1 개별 제어 — `[ADDR]o[N]`, `[ADDR]x[N]`

`N`은 1–8입니다.

```text
1o3  → 1O3,ON
1x3  → 1X3,OFF
```

### 4.2 전체 제어 — `[ADDR]b[HEX]`

8비트 마스크를 16진수로 지정합니다. 최하위 비트(bit 0)가 밸브 1입니다.

```text
1b00 → 1B00,OK       모든 밸브 OFF ( 0b00000000 = 0x00 )
1b05 → 1B05,OK       밸브 1·3 ON, 나머지 OFF ( 0b00000101 = 0x05 )
1bFF → 1BFF,OK       모든 밸브 ON ( 0b11111111 = 0xFF )
```

`0x` 접두어는 붙이지 않습니다. 응답 마스크는 항상 대문자 16진수 두 자리입니다.

### 4.3 상태 조회 — `[ADDR]?V`, `[ADDR]?V/`

```text
1?V  → 1?V,1,0,1,0,0,0,1,0
1?V/ → 1?V/,45
```

`?V`의 8개 필드는 밸브 1–8 순서이며 ON=1, OFF=0입니다. 위 두 응답은 같은 상태입니다.

프로필 미등록 장비는 릴레이 출력을 강제로 OFF로 유지합니다. 이때도 설정 ACK는 요청 내용을 표시할 수 있으므로 ACK만으로 실제 적용 상태를 판단하지 말고 `?V`를 확인하세요.

## 5. 압력 설정과 적용값 조회

### 5.1 설정 — `[ADDR]p[REG],[VALUE]`

| 항목 | 규칙 |
| --- | --- |
| `REG` | 1–4 |
| `VALUE` | 음수가 아닌 십진수, 단위 kPa |
| 분해능 | 0.1 kPa |
| 소수점 두 자리 이상 | 둘째 자리에서 반올림 |
| 정상 제어 하한 | 반올림된 값이 1.0 kPa 미만이면 DAC raw 0 |
| 상한 | 채널 최대압 및 출력 보정 범위에 따라 제한 |

```text
1p1,20      → 1P1,20.0,OK
1p2,20.55   → 1P2,20.6,OK
1p1,0.5     → 1P1,0.0,OK
1p1,0       → 1P1,0.0,OK
```

- 정상 응답은 `[ADDR]P[REG],[적용값],OK`입니다.

- 생략형 명령: `1p20.5`는 1번 채널의 20.5 kPa 설정입니다. `1p,20.5`는 올바른 생략형이 아닙니다. 새 구현에서는 채널을 항상 명시하세요.

- 숫자는 정수부가 필수입니다. `-1`, `+1`, `.5`, `1.`, `1e2`, `10xyz`는 허용하지 않습니다. 장비 제공 범위를 넘는 입력을 사용하지 마세요.
- 장비 오작동 방지를 위해 1 kPa 미만의 작동 범위는 기능을 제공하지 않습니다.

### 5.3 최대압과 보정

- 최대압은 `?I`의 채널별 값을 사용합니다.
- 출력에는 채널별 저장 보정표 또는 해당 채널에 적용되는 기본 보정이 사용됩니다. (출고 시 제어 압력 보정 진행)

### 5.4 설정압 조회 — `[ADDR]?P[REG]`

**활성 상태의 1번 채널만 응답에서 채널 숫자를 생략합니다.**

| 요청 | 활성 채널 응답 예 | 비활성 채널 응답 |
| --- | --- | --- |
| `1?P`, `1?P0`, `1?P1` | `1?P,20.5` | `1?P1,DISABLED` |
| `1?P2` | `1?P2,20.5` | `1?P2,DISABLED` |
| `1?P3` | `1?P3,20.5` | `1?P3,DISABLED` |
| `1?P4` | `1?P4,20.5` | `1?P4,DISABLED` |

응답 압력은 항상 소수 한 자리입니다. 

## 6. 센서 측정값 조회

### 6.1 전체 측정압 — `[ADDR]?A`

```text
1?A → 1?A,18.3,0.4,DISABLED,DISABLED
```

레귤레이터 1–4 순서의 네 필드입니다. 활성 채널은 ADC 보정표로 변환한 kPa를 소수 한 자리로 표시합니다. 미장착/비활성 채널은 `DISABLED`입니다.

### 6.2 개별 측정압 — `[ADDR]?A[REG]`

```text
1?A1 → 1?A1,18.3
1?A3 → 1?A3,DISABLED
```

`REG`는 1–4입니다. `?P`와 달리 활성 1번 채널도 응답에 `1`이 붙습니다. `?A0`은 허용하지 않습니다.


## 7. 응답과 오류 처리

### 7.1 기본 오류 응답

```text
ERR-301
1?P3,DISABLED
```

- 오류 줄에는 장비 주소가 붙지 않습니다.
- 정상 응답의 필수 앞부분을 파싱하고 부가 오류 설명을 허용하세요.

### 7.2 오류 코드

| 코드 | 의미 |
| --- | --- |
| `ERR-101` | 주소/본문을 해석할 수 없는 프레임. USB에서는 응답, RS485에서는 무응답 처리 |
| `ERR-102` | 지원하지 않는 명령 |
| `ERR-201` | 밸브 번호 오류(1–8) |
| `ERR-202` | 레귤레이터 번호 또는 `?A`/`?P` 조회 형식 오류 |
| `ERR-203` | 노드 주소 오류(1–F) |
| `ERR-204` | 밸브 비트마스크 오류(00–FF) |
| `ERR-205` | 압력 숫자 형식 오류 |
| `ERR-301` | 비활성 레귤레이터 제어 요청 |
| `ERR-302` | 조회 대상 비활성. 주로 verbose `DISABLED` 응답의 추가 필드 |
| `ERR-303` | USB 직결·주소 0 전용 명령을 다른 경로/주소로 요청 |

`?P1abc`, `p1,10xyz` 같은 불필요 문자가 포함된 명령은 허용되지 않습니다. 다만 전체 프레임 길이 초과는 2.1절의 버퍼 제한을 따릅니다.

### 7.3 부팅과 RS485 중계

- 앱 초기화 시 USB에 현재 장비 주소의 `?I` 형식 배너를 한 번 출력합니다. RS485에는 부팅 배너를 보내지 않습니다.
- USB 포트 열기가 리셋을 일으키는지는 보드·드라이버·DTR/RTS 설정에 따라 달라집니다. 배너 수신을 전제로 하지 말고 `?I`를 직접 요청합니다.
- USB 브리지는 원격 조회 응답, 설정 ACK, 주소 ACK, `ERR-...` 줄을 USB로 전달합니다.
- `ERR-...`에는 주소가 없으므로 여러 장비를 데이지 체인으로 묶어 사용할 경우 오류는 USB를 직접 연결하여 파악하여야합니다.

## 8. 상태 저장과 재시작

- 장비는 모델/HW/SN, 주소, 장착 채널·최대압, 보정표, 응답 모드와 출력 상태를 저장합니다.
- 밸브 및 압력 제어 상태는 마지막 변경 후 약 1500 ms 동안 추가 변경이 없을 때 장비 내부 메모리에 저장됩니다. (갑작스런 전원 단선으로 문제가 생기는 경우 자동 복구를 위함)
- 전원 복귀 시 저장된 릴레이· 압력 출력이 복원될 수 있습니다.
- 유효한 장비 정보를 읽지 못하면 출력이 제한됩니다. 정상 운전을 시작하지 말고 본사에 문의하세요.

## 9. 호스트 구현 순서

1. 115200 / 8N1로 연결하고 수신 바이트를 LF 단위로 조립합니다.
2. 대상 주소에 `?I`를 보내 모델·HW·FW·최대압을 확인합니다.
3. `?A` 또는 개별 조회로 실제 활성 채널을 확인합니다. 최대압이 0인 채널은 제어 대상에서 제외합니다.
4. 필요한 출력 명령을 한 건씩 전송하고 ACK·오류·타임아웃을 처리합니다.
5. `?V`, 활성 채널별 `?P[REG]`, `?A`로 상태를 주기적으로 갱신합니다.
6. ACK 적용값과 측정압을 별도 항목으로 표시합니다. `DISABLED`를 숫자 0과 구분합니다.

예시 흐름(주소 1, 채널 1·2 활성):

```text
TX 1?I
RX 1?I,TKPM-D11,v002,v2.8.1,PMABC001,100,100,0,0
TX 1p1,20.5
RX 1P1,20.5,OK
TX 1?P1
RX 1?P,20.5
TX 1?A
RX 1?A,18.3,0.4,DISABLED,DISABLED
TX 1?V/
RX 1?V/,00
TX 1p1,0.5
RX 1P1,0.0,OK
TX 1p3,10
RX ERR-301
```
